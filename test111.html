🔬 Labo - Récupération Titre Live Twitch

Utilise l'API DecAPI (publique, sans CORS) pour récupérer le titre du live

Méthode 1 : DecAPI /twitch/title (Recommandée)

Utilise l'API publique api.decapi.me/twitch/title/{channel} qui retourne directement le titre du live. C'est la même API qu'on utilise déjà pour les avatars.

fetch('https://api.decapi.me/twitch/title/hugodelire') .then(r => r.text()) .then(title => console.log(title));

Méthode 2 : DecAPI /twitch/status

Retourne le statut complet : "Titre du live (Jeu)" ou "offline" si pas de live.

fetch('https://api.decapi.me/twitch/status/hugodelire') .then(r => r.text()) .then(status => console.log(status));

Méthode 3 : DecAPI /twitch/game

Retourne le jeu en cours (utile pour vérifier si le live est actif).

fetch('https://api.decapi.me/twitch/game/hugodelire') .then(r => r.text()) .then(game => console.log(game));

Méthode 4 : Toutes les infos combinées

Récupère titre, jeu et statut en parallèle pour avoir une vue complète.

💡 Pourquoi ça marche ? DecAPI est une API publique conçue pour être appelée depuis n'importe où (navigateurs, bots, scripts). Elle a des headers CORS permissifs qui permettent les requêtes cross-origin, contrairement à l'API Twitch officielle qui bloque tout sauf les domaines autorisés.
