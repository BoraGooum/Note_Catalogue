🔬 Labo - Récupération du Titre de Live Twitch

Test de 4 méthodes pour récupérer le titre du live de hugodelire

Méthode 1 : fetch() direct vers la page Twitch Client-Side

Tentative de récupération directe via JavaScript en utilisant fetch() vers la page HTML de Twitch.

fetch('https://www.twitch.tv/hugodelire') .then(r => r.text()) .then(html => { const parser = new DOMParser(); const doc = parser.parseFromString(html, 'text/html'); const title = doc.querySelector('p.CoreText-sc-1txzju1-0'); console.log(title?.textContent); });
⚠️ Problème CORS : Twitch bloque les requêtes cross-origin depuis un navigateur. Cette méthode échouera systématiquement.

Méthode 2 : Proxy CORS (allorigins.win) Client-Side

Utilisation d'un service proxy pour contourner CORS. Le proxy récupère la page et nous la renvoie.

fetch('https://api.allorigins.win/raw?url=' + encodeURIComponent('https://www.twitch.tv/hugodelire')) .then(r => r.text()) .then(html => { const parser = new DOMParser(); const doc = parser.parseFromString(html, 'text/html'); const title = doc.querySelector('p.CoreText-sc-1txzju1-0'); console.log(title?.textContent); });
ℹ️ Peut fonctionner mais dépend d'un service tiers (instable, lent, peut être bloqué par Twitch).

Méthode 3 : yt-dlp --print title Server-Side Recommandé

Ce qu'on fait déjà ! Utilisation de yt-dlp côté serveur pour extraire le titre. C'est la méthode la plus fiable car yt-dlp gère déjà l'authentification, les cookies, et l'API Twitch.

# Python (server.py) import subprocess def get_title(url): result = subprocess.run( ["yt-dlp", "--print", "title", "--no-warnings", url], capture_output=True, text=True, timeout=15 ) return result.stdout.strip() # Exemple title = get_title("https://www.twitch.tv/hugodelire") print(title) # → "[Live] On joue à Minecraft !"
✅ Avantages : Fiable, rapide, gère les cookies automatiquement, déjà implémenté dans ton serveur.
❓ Question : Est-ce que le titre récupéré est correct ? (Parfois yt-dlp retourne le nom de la chaîne au lieu du titre du live)

Méthode 4 : Scraping HTML côté serveur (urllib) Server-Side

Récupération directe du HTML de la page Twitch côté serveur Python, puis parsing avec BeautifulSoup ou regex pour extraire le titre.

# Python (server.py) import urllib.request from html.parser import HTMLParser class TitleParser(HTMLParser): def __init__(self): super().__init__() self.in_title = False self.title = None def handle_starttag(self, tag, attrs): attrs_dict = dict(attrs) if tag == 'p' and 'CoreText-sc-1txzju1-0' in attrs_dict.get('class', ''): self.in_title = True def handle_data(self, data): if self.in_title: self.title = data self.in_title = False def get_title_scrape(channel): url = f"https://www.twitch.tv/{channel}" req = urllib.request.Request(url, headers={ 'User-Agent': 'Mozilla/5.0 (X11; Linux x86_64) AppleWebKit/537.36' }) html = urllib.request.urlopen(req, timeout=10).read().decode('utf-8') parser = TitleParser() parser.feed(html) return parser.title # Exemple title = get_title_scrape("hugodelire") print(title)
⚠️ Risques : Twitch peut bloquer les scrapers, la structure HTML peut changer (classes CSS dynamiques), nécessite de gérer les cookies manuellement.
💡 Alternative : Utiliser l'API GQL Twitch (comme pour les avatars) qui retourne aussi le titre du live.
