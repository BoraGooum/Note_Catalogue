🔬 Labo - Récupération Titre Live Twitch

Test de 8 méthodes pour récupérer le titre du live (compatible GitHub Pages)

1. API Twitch GQL (Client-ID public)

Utilise l'API GraphQL officielle de Twitch avec le Client-ID public (celui qu'on utilise pour les avatars).

2. DecAPI direct

API publique DecAPI (api.decapi.me/twitch/title).

3. DecAPI via corsproxy.io

DecAPI passée par un proxy CORS public (corsproxy.io).

4. Scraping HTML twitch.tv via allorigins

Récupère la page HTML de twitch.tv via api.allorigins.win et cherche la balise <h4 title="...">.

5. Scraping HTML m.twitch.tv via corsproxy.io

Version mobile via corsproxy.io, HTML souvent plus simple.

6. Scraping HTML via thingproxy.freeboard.io

Autre proxy CORS public pour contourner les restrictions.

7. API StreamElements (si intégrée)

StreamElements expose parfois les infos de stream via leur API publique.

8. Vérification CORS (diagnostic)

Teste si les APIs répondent correctement aux requêtes OPTIONS (preflight CORS).
